cryopods, viewport, computer, furnishings and lighting sprites. The active player
is under `assets/art/sprites/pegasus/player/`.

Edit architecture in `pegasus/world.tscn` and `pegasus/tileset.tres`; PNG exports
never generate maps. Original copied pre-Alpha-0.2 cabin artwork remains excluded
under `archive/godot/`. Historical attribution is retained, not newly cleared.
