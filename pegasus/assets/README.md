# Pegasus asset sources

Assets were copied from the existing repository without modifying originals:

- `backgrounds/matrix-opening.jpg`: archived Matrix opening artwork.
- `sprites/player_snoblin.png`: archived Matrix player sheet.
- `tilesets/interiors_free_16x16.png`: archived interior artwork.
- `tilesets/16x16.png`: archived shared forest artwork.

Attribution and source documentation remain in `legacy/pygame/`; this copy
establishes no new authorship or licensing claim. No new artwork was added.
The authoritative map is `pegasus/world.tscn`, with external `pegasus/tileset.tres`.
Original copied TMX/TSX authoring files and their converters have been retired;
the untouched archive and Git history preserve the original sources.
