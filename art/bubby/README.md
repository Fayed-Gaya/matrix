# Provisional Bubby art sources

Original local geometric pixel-art SVGs for a generic apartment, small outdoor
area and pigeon. No Kate apartment/reference photos or personal details were
available. These are fictional placeholders, not an approved depiction.

The atlases are 128×128 (sixteen 32px tiles); pigeon is 32×32. Preserve dimensions,
cell positions and nearest filtering when exporting matching PNGs to
`levels/bubby/assets/`. Editable Aseprite copies are provided for that workflow;
edit either source format deliberately, since they do not auto-synchronize.
Native scene composition and collision stay in Godot. No paid generation used.
The playable avatar/music are retained Zelda tutorial assets, not this original
art; unresolved attribution/permission issues remain in the licensing audit.
